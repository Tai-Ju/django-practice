Features
功能介紹
🏠
首頁
精選商品展示、品牌形象呈現，自動導向電商首頁。
🛍️
商品列表
從資料庫讀取 Product Model，以網格卡片方式呈現，含商品圖片與價格。
👤
會員頁面
會員專區入口，可延伸為登入/註冊功能。
⚙️
Django Admin
內建後台管理，可新增、編輯、刪除商品，無需另外開發 CMS。
🚀
Railway 部署
內含 Procfile、railway.json 設定，可一鍵部署至 Railway 雲端平台。
🎨
自訂樣式
使用 Google Fonts（Noto Sans TC、Outfit）+ Whitenoise 靜態檔案管理。

Install
本地運行
01
Clone 專案
git clone https://github.com/Tai-Ju/django-practice.git
cd django-practice
02
建立虛擬環境並安裝依賴
python -m venv .venv
.venv\Scripts\activate  # Windows
# source .venv/bin/activate  # macOS/Linux

pip install -r requirements.txt
03
資料庫遷移
python manage.py migrate
04
建立管理員帳號（選填）
python manage.py createsuperuser
05
啟動開發伺服器
python manage.py runserver

# 開啟瀏覽器：http://127.0.0.1:8000/
